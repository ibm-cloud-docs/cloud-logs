# Configuring your instance preferences in an {{site.data.keyword.logs_full_notm}} instance
{: #account_preferences}

In {{site.data.keyword.logs_full_notm}}, you can configure the default homepage for users, change the time zone settings, change the display format for dates, and enable the aggregation of alerts into a metric. *Preferences*. Preferences apply to user sessions across all views and pages. You can configure Preferences only through the UI.
{: shortdesc}


## About preferences in an {{site.data.keyword.logs_full_notm}} instance
{: #account_preferences_ov}

You can change any of the following preferences in an {{site.data.keyword.logs_full_notm}} instance:

- `User-level default homepage`

    `User-level default homepage` controls which section of the UI opens when a user logs in an {{site.data.keyword.logs_full_notm}} instance.

    By default, when a user logs into an {{site.data.keyword.logs_full_notm}} instance, the landing page is set to the *Home Dashboard*.

    Valid options for the User-level default homepage setting are: `Home Dashboard`, `Custom Dashboards`, `Logs Explorer`, `Incidents`, and `Livetail`.

    Through this setting, you can change the default landing page when a user logs in to any valid option.

    If a user logs into an intance and changes the default view or default custom dashboard, then, the default homepage that is launched when the user logs in is set to the preferences that the user configures for `Custom Dashboards` or `Logs Explorer`.

- `Change time zone settings`

    You can select if you want times to be displayed in your local time or in Greenwich Mean Time (GMT). GMT is also known as Coordinated Universal Time (UTC).

    Changing your time zone only affects time displayed and generated by the {{site.data.keyword.logs_full_notm}} UI. It does not affect timestamps within log records (including log record timestamps displayed in the UI) or timestamps within alerts and incidents.
    {: important}

    This setting applies to all time zones across your {{site.data.keyword.logs_full_notm}} instance.

    Valid options are: `Local time` and `Greenwich Mean Time (GMT)`.

- `Change Your date format view settings`

    This setting applies to all date formats across your {{site.data.keyword.logs_full_notm}} instance.

    Valid options are: `DD/MM/YYYY` and `MM/DD/YYYY`.

- `Aggregate alerts into a gauge-type metric: cx_alerts`

    By default, this setting is enabled.

    When the setting is enabled, {{site.data.keyword.logs_full_notm}} generates a metric for every alert that triggers or is resolved.

    You can add this metric to a custom dashboard to monitor alerts in your instance. For more information, see [custom dashboards](/docs/cloud-logs?topic=cloud-logs-create_dashboards) and [Creating a IBM Cloud Logs gauge widget](/docs/cloud-logs?topic=cloud-logs-widget_gauge).

    

## How can I change the default view in the Explorer Logs that is launched by default when a user logs into an {{site.data.keyword.logs_full_notm}} instance
{: #account_preferences_faq1}

Account preferences apply to user sessions across all views and pages.

By default, when a user launches the *Explorer Logs > Logs* section or logs into an {{site.data.keyword.logs_full_notm}} instance that has the `User-level default homepage` set to *Explorer Logs*, the user lands on the default view layout.

As a user, you can configure the column layout, the filter options and the view mode such as JSON, condensed, 1 line, or 2 lines in the default Logs view. Then, you can save this configuration and set it as your default view. For more information, see [Creating a custom view as default](/docs/cloud-logs?topic=cloud-logs-custom_views_default).

Then, the default homepage that is launched when the user logs in is set to the default view that the user hascconfigured for `Logs Explorer`.


## Launch the Preferences UI in an {{site.data.keyword.logs_full_notm}} instance
{: #account_preferences_launch}

Complete the following steps to launch the preferences page in an {{site.data.keyword.logs_full_notm}} instance:

1. In the {{site.data.keyword.cloud_notm}} console, click the **Navigation menu** icon ![Navigation menu icon](../icons/icon_hamburger.svg) > **Observability** > **Logging** > **Instances**.

2. Select the {{site.data.keyword.logs_full_notm}} instance. The default homepage opens.

3. Click the **Avatar** icon ![Avatar icon](/icons/avatar.svg) > **Preferences**.

    The *Preferences* page opens.

Next, change any setting.
